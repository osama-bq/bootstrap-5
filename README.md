# Bootstrap 5 Projects

A collection of frontend projects built primarily with **Bootstrap 5**. The repository demonstrates practical use of Bootstrap's responsive grid system, utility classes, components, forms, navigation, cards, and responsive layouts across different website concepts.

# Projects

## 1. EMS-2.0

**Folder root:** `./EMS-2.0/`

**Live Demo:** https://cosmic-cajeta-a3ec46.netlify.app/

### Overview

EMS-2.0 is an **Employee Management System** frontend. It contains a login page and separate interfaces for viewing the dashboard, employees, and jobs.

The project focuses on building a structured administrative interface using Bootstrap's responsive layout and UI utilities.

### Pages

| Page | File |
|---|---|
| Login | `index.html` |
| Dashboard | `dash.html` |
| Employees | `employees-list.html` |
| Jobs | `jobs-list.html` |

### Bootstrap Usage

- Responsive container and grid system
- Navbar and navigation components
- Cards and dashboard sections
- Responsive tables
- Forms and form controls
- Buttons
- Spacing and display utilities
- Responsive alignment
- Bootstrap Icons / utility classes where applicable

### Technologies

- HTML5
- CSS3
- Bootstrap 5.3.8
- Bootstrap JavaScript Bundle

### Folder Structure

```text
EMS-2.0/
├── index.html
├── dash.html
├── employees-list.html
└── jobs-list.html
```

## 3. Prime-Inspire

**Folder root:** `./Prime-Inspire/`

**Live Demo:** https://gentle-mousse-4aae8c.netlify.app/

The project makes extensive use of Bootstrap 5 for responsive page composition and reusable interface elements while combining it with custom CSS for visual styling.

| About | `about.html` |
| Courses | `courses.html` |

| Blog | `blog.html` |
| Single Post | `single-post.html` |
| FAQ | `faq.html` |

### Bootstrap Usage

- Course and content cards
- Buttons and badges
- Forms
- Flexbox utilities
- Spacing utilities
